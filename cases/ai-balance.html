AI Balance — ИИ-коуч по балансу в жизни

ИИ-продукт для контроля питания и физической активности: КБЖУ, спорт, водный баланс, приём БАДов, отслеживание прогресса и достижение цели — похудение, рекомпозиция или набор массы.

Задача

Запустить MVP персонального ИИ-коуча по питанию и тренировкам, который не выдаёт шаблонные советы, а опирается на реальные данные пользователя — цель, вес, активность, привычки. Нужно было уложиться в сжатые сроки и сразу заложить архитектуру, готовую к росту базы пользователей.

Решение

Собрали продукт вокруг трёх опор: подбор программы тренировок под цель, дневник питания с базой из 20 000+ продуктов и ИИ-коуч, который анализирует прогресс и даёт рекомендации в чате. Разработку вели итеративно — от кликабельного прототипа до релиза MVP с последующими доработками по фидбеку первых пользователей.

Стек

Frontend — React, TypeScript, Tailwind CSS. Backend — Node.js (NestJS), PostgreSQL. Интеграция с LLM API для генерации персональных рекомендаций коуча. Инфраструктура развёрнута в облаке с CI/CD для быстрых релизов.

Роль команды

Avilon.IT вела проект полным циклом: аналитик проработал требования и пользовательские сценарии, UX/UI-дизайнер собрал интерфейс, два frontend- и два backend-разработчика реализовали продукт, QA-инженер тестировал перед каждым релизом. Команда сопровождает продукт и после запуска.
