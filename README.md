# Avilon.IT — сайт-визитка

Статический сайт компании Avilon.IT (IT-аутсорсинг и аутстаффинг). Чистые HTML/CSS/JS, без фреймворков и сборщиков.

## Структура проекта

```
/
├── index.html          — главная страница
├── css/
│   └── styles.css      — общие стили (переменные, компоненты, адаптив)
├── js/
│   └── main.js         — общие скрипты (меню, FAQ-аккордеон, форма)
├── assets/
│   └── images/         — изображения
└── README.md
```

`css/styles.css` и `js/main.js` — общие файлы, переиспользуются на всех страницах сайта. При добавлении новых страниц (`services.html`, `contacts.html` и т.д.) подключайте те же файлы, не дублируя стили и скрипты.

## Дизайн-система

- Шрифты: [Manrope](https://fonts.google.com/specimen/Manrope) (основной текст и заголовки), [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) (лейблы, цифры) — подключены через Google Fonts.
- Акцентные цвета: терракотовый `#C4622D`, бирюзовый `#2E7D74`.
- Тёмные секции (шапка, hero, футер): графитово-синий `#262B39`.
- Все цвета и отступы вынесены в CSS-переменные в начале `styles.css`.
- Иконки — инлайн SVG, без сторонних библиотек.

## Запуск

Файл `index.html` можно открыть напрямую в браузере, либо поднять локальный сервер, например:

```
npx serve .
```
